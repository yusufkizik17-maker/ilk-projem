# Öztek sitesini yayımlama

Bu site doğrudan HTML, CSS ve JavaScript ile çalışır. Derleme, veritabanı veya sunucu kurulumu gerekmez.

## Ücretsiz bağlantı

1. https://app.netlify.com/drop adresinde kendi hesabınızla giriş yapın.
2. `oztek-site.zip` dosyasını bilgisayarınızda açın.
3. İçinde `index.html` bulunan klasörü yükleme alanına bırakın.
4. Netlify siteniz için HTTPS bağlantısı oluşturur. Uygun olan bir site adını hesap ayarlarından seçebilirsiniz.

Yayımlama hesabı site sahibine ait olmalıdır. Dosyaların hazırlanması sitenin internete yayımlandığı anlamına gelmez.

## Kendi hosting hesabınız

`index.html`, `style.css`, `script.js`, `favicon.svg` ve `assets` klasörünü alan adının web köküne (çoğunlukla `public_html`) yükleyin. `assets` klasör yapısını koruyun. Hosting panelinden HTTPS sertifikasını etkinleştirin.
